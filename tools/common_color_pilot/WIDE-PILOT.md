# 선 굵기 후속 예비실험 v5

v3에서 고정한 두 색 경로와 세 색쌍을 유지하고, 선 굵기를 1·2·3·4·6·8·12·16px로 늘린다.
총 384문항이며, 48문항씩 8블록으로 나눈다. 각 색 경로·색쌍·굵기 조합에서 정답 위치와 다른 색의 정체를 균형화한다.

이 폴더에서 실행한다.

```bash
python wide_pilot.py --self-test
python wide_pilot.py --prepare
python run_v5.py
```

`--prepare`에는 비공개 `raw/_design_v3/design.json`이 필요하다. 기존 v5 계획과 내용이 다르면 덮어쓰지 않는다.
`run_v5.py`와 `넓은굵기_시작.cmd`는 프로그램이 인식하는 해상도가 3840×2160일 때만 시작한다.
이 검사는 실제 화면의 1:1 픽셀 표시나 색도 검증을 대신하지 않는다.

응답과 설정은 Git에서 제외한 `raw/v5/`에 저장한다. 기존 회차는 당시 프로그램으로 이어서 실행한다.
색 경로를 이전 탐색 자료에서 골랐으므로 결과도 탐색적으로 해석한다. 본실험 C80이나 일반적인 굵기 효과를 확정하는 검사가 아니다.
