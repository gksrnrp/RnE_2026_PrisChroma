# 넓은 굵기 후속 실험 v5

v3와 같은 색쌍으로 굵기만 늘린 탐색 후속 실험이다. 기존 v2/v3/v4·동결 본실험을 수정하지 않는다.

- v3 계획(`raw/_design_v3/design.json`)의 색 경로 2개와 색쌍 3단계를 **그대로** 쓴다.
- 바뀐 것은 굵기뿐이다: 1·2·3·4·**6**·8·**12**·**16** px (v3는 1·2·3·4·8 px).
- 2색 × 8굵기 × 3색차 × 8반복 = **384문항**. 각 조합에서 정답 위치 4곳 × 다른 색 정체 2가지를 한 번씩 제시한다.
- 48문항 균형 블록 8개, 블록 안 순서 무작위, 48문항마다 휴식. 연습 1문항(피드백), 본문 피드백 없음.
- 선 길이 240 px, 배경 RGB 117, 안티앨리어싱 없는 2×2 4AFC. 관찰 조건은 v3와 같게 유지한다.

## 설계 근거

2026-11-09 가상 참가자 시뮬레이션(일반 가정값, 조건당 150명)에서 v3(240문항)는 "4 px 꺾임"을 57%,
같은 240문항에 굵기만 8개로 늘린 설계는 56%, 굵기 8개 × 8회(384문항)는 68% 판별했다.
4 px 꺾임 가설은 이미 본 v2/v3 자료에서 나온 사후 가설이며, 이 후속 실험도 탐색 결과로만 보고한다.

## 실행

```
python wide_pilot.py --self-test   # 합성 계획으로 검사, 사람 자료 없음
python wide_pilot.py --prepare     # v3 계획에서 v5 계획 고정 (덮어쓰기 없음)
넓은굵기_시작.cmd                   # 실험 시작
```

응답은 Git 제외 `raw/v5/<가명>/`에 문항마다 저장되며 같은 가명으로 이어 할 수 있다.
