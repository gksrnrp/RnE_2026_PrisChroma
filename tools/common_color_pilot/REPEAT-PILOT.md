# 같은 색쌍의 굵기별 반복 비교 v3

기존 v1/v2·동결 본실험을 수정하지 않는 별도 예비실험이다. 원래 288회와 합산하지 않는다.

- 공통 색 경로 2개 × 굵기 1/2/3/4/8px × 색차 3단계 × 8반복 = 240문항.
- 동일 색 경로·색차에서는 모든 굵기에 정확히 같은 RGB 두 개를 표시한다.
- 각 조합에서 정답 위치 1~4 × 홀수색 A/B 조합을 한 번씩 제시한다.
- 30문항 균형 블록을 8번 반복하며 블록 안에서는 색·굵기·색차 순서를 섞는다.
- 본문 밖 연습 1문항. 정답 피드백은 연습만 제공한다.
- 30문항마다 쉬거나 종료 가능, 매 문항 fsync 저장, 같은 v3 가명 코드로 재개.
- 실행: `반복비교_시작.cmd`. 예전 `시작.cmd`는 v2이므로 구분한다.

## 선별 규칙과 제한

이전 완료 288회에서 굵기를 합산한 색차 단계별 정답률만 사용한다. 큰 두 색차와 작은 두 색차의
정답률 차이가 큰 색 경로 중, 큰 두 단계 평균과 최대 단계 정답률이 각각 75% 이상인 상위 2개를 고른다.
**2px 대 4px 차이 등 굵기별 우위는 선별에 사용하지 않는다.**
각 색 경로에서 내부 수준 중 처음으로 합산 정답률 65% 이상인 수준과 양옆을 3단계로 삼는다.
65%는 범위 탐색을 위한 선택 규칙이지 추정 C80이나 검증된 목표 성능이 아니다.
이 선택은 이미 본 v2 자료로 정한 후속 탐색이며 사전등록 확증 분석이 아니다.
개인별 진단/전체 색 공간 일반화/보정 효과를 주장하지 않는다.

이전 자료는 하강 순서·희소 반복의 한계가 있다. 선별 규칙으로 골랐다고 범위가 반드시 적절한 것은 아니다.
3개 색차 중 구별 한계를 끼우는 범위가 없거나 반복 변동이 크면 C80은 미추정으로 남긴다.
각 색×굵기×색차가 8회이므로 0~8 정답 수와 불확실성을 우선 보고한다.
2개 색 경로·단일 참가자·고정 장치 조건의 탐색이며, 유리한 조합만 골라 효과가 확인됐다고 쓰지 않는다.

## 화면 및 보관

길이 240px, 회색 배경 RGB117, 2×2 4AFC, 안티앨리어싱 없는 단색 직사각형이다.
1px까지 이미지 내 정확한 굵기는 자동검사하지만 실제 모니터 1:1 출력/색도계 검증과는 다르다.
화면 배율·거리·색관리·모니터는 동일하게 유지한다. 화면을 벗어나면 멈추고 같은 문항을 재제시하며 사건을 남긴다.
재제시된 문항은 이후 품질 점검에서 구분해야 한다.

선별 근거와 동결 색쌍은 Git 제외 `raw/_design_v3/design.json`, 새 응답은 `raw/v3/<가명>/`이다.
실명은 입력하지 않는다. 기존에 동의한 참가자에게만 시행한다.
계획/두 실행 모듈의 해시가 달라지면 기존 회차에 이어 쓰지 않는다. 원자료 삭제나 자동 덮어쓰기는 하지 않는다.
