# 새 굵기 6px 예측 확인 (v4 탐색 후속)

기존 동결 프로토콜의 validation 단계나 연구 승인 해제가 아니다. v3 탐색 모델을 같은 참여자의 새 6px 응답으로 비교한다.
원래 240회/288회 응답과 모델은 변경하지 않는다. 새 응답으로 모델을 다시 맞춰놓고 검증했다고 하지 않는다.

- 6px는 v3에서 측정하지 않은 굵기다. 두 색 경로 × 5색차 × 12회 =120문항.
- 각 색 경로의 모든 모델상 C80 최소/최대를 이용해 다섯 목표 색차를 정하고, 기존 선형 RGB 경로에서 양자화된 색쌍을 만든다.
- 목표 규칙은 min의 .60/.85배, min/max 중간값, max, max의 1.25배. 어느 모델에도 같은 색쌍을 사용한다.
- 4AFC, 같은 배경/길이/형식. 반복·위치·색 정체를 균형화하며 색차 순서는 섞는다. 30문항씩4블록, 별도 연습1문항.
- 방금 v3을 한 같은 참가자가 같은 안경·모니터·거리로 진행한다. 실제 동일인/광학적 조건이 독립 확인된 것은 아니다.
- 시작 프로그램은 `6px예측확인_시작.cmd`이며 기존 프로그램과 구분한다.

계획과 모델 스냅샷은 `raw/_design_v4/`, 새 응답은 `raw/v4/<가명>/`에 Git 제외 저장한다.
준비 후 모델/계획을 바꾸지 않는다. 세 모형 모두의 새 정답확률 예측에 대한 Brier/logloss를 전체/색 경로별로 비교한다.
본 실험 중 성적에 맞춰 색차·모델·성공 기준을 바꾸지 않는다. 새 자료가 적거나 차이가 작으면 구분 불가를 보고한다.
이 검사는 확률 예측의 새 자료 점검이며, C80 정밀 추정/coverage 검증/임상적 일반화/최소 보정 효능의 확증과는 다르다.
필요한 색차가 포함되지 않거나 반응이 불안정하면 역치를 외삽하지 않는다. 원설정과 게이트는 수정하지 않는다.
