## 500 mm 관찰거리 후보의 시각도

342 mm / 2560 px에서 픽셀 피치는 약 0.133594 mm/px다.

| 용도 | 굵기 | 시각도 |
|---|---:|---:|
| 교정 | 4 px | 0.061235° |
| 검증 후보 | 6 px | 0.091852° |
| 교정 | 8 px | 0.122470° |
| 검증 후보 | 11 px | 0.168396° |
| 교정 | 16 px | 0.244939° |

모두 Szafir 선 측정범위 0.05–0.35° 안이다. 관찰거리는 목표 500 mm,
사전 허용범위 ±20 mm로 두고 노트북·의자 위치 표시와 세션/휴식 전후 재측정으로
통제하는 후보안이다. 실제 통제 가능성을 현장에서 확인하기 전에는 동결하지 않는다.

## 아직 확인할 항목

- [ ] GameVisual 현재 모드가 `Default`이고 세션 동안 바뀌지 않는다.
- [ ] HDR, 야간 모드, 자동 밝기, 콘텐츠 기반 밝기 변경이 꺼져 있다.
- [ ] 전원 어댑터 연결과 전원 모드를 고정했다.
- [ ] 관찰거리 500±20 mm의 표시·재측정 절차를 실제로 시험했다.
- [ ] 조도계로 고정 위치에서 주변 조도를 3회 측정하고 허용범위를 정했다.
- [ ] 실제 장치의 Windows 식별자와 CPython/Tk 버전을 config에 기록했다.
- [ ] Per-Monitor V2 DPI, 144 DPI, 2560×1440 전체화면과 1:1 PNG를 확인했다.
- [ ] 실제 raster 캡처와 연습 6–10회에서 제시·응답·중단·저장을 확인했다.
- [ ] 참가자별 CVD/severity/lapse 출처와 윤리·동의 절차가 승인됐다.

위 항목과 config-bound parameter recovery가 끝날 때까지
`human_data_collection_allowed=false`를 유지한다.
