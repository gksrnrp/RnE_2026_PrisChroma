**완료 기준:** 시뮬레이터 구현이 저장소에 하나만 존재하고 41개 테스트가 통과한다.

### 2. `run_baseline()` 연결

**목표:** SLIC으로 뽑은 영역 대표색을 이창민의 보정 함수에 넘긴다.

- `baseline.py`의 `run_baseline()` 인자·반환 형태 확인

- `baseline.py`는 **수정하지 않는다.** 호출만 한다

**완료 기준:** 실제 이미지 한 장을 넣으면 보정 결과가 나온다.

### 3. 실제 이미지 수집

**목표:** 평가용 실제 화면 20~30장 확보.

| 범주 | 수량 |

| 노선도 | 4~5 |
| UI 화면 | 5~6 |
| 색각 검사표 | 3~4 |

- `data/real/sources.csv`에 출처·라이선스 기록
- 색이 정보를 구분하는 이미지만. 색이 장식인 것은 제외

**완료 기준:** `data/real/images`에 20장 이상, `sources.csv` 작성 완료.

### 4. 측정 실행 → 정훈 전달 (우선순위 높음)

**목표:** 한정훈이 2차 실험 조건을 정할 수 있게 크기·거리 통계를 넘긴다.

```powershell
python -c "from measure_pairs import measure_directory; measure_directory('../data/real/images','../results/measurements_real.json', n_segments=800, capture_meta={'screen_diagonal_inch':15.6,'screen_resolution':[1920,1080],'viewing_distance_cm':50,'source':'노선도 캡처'})"

python -c "from export_tables import export_all; export_all('../results/measurements_real.json','../results')"
```

`capture_meta`의 화면 크기·관찰 거리는 **실제 값으로 채운다.** 비워두면 시각도 환산이 불가능하다.

산출물:

| 파일 | 받는 사람 | 용도 |
|---|---|---|
| `results/conditions.md` | 한정훈 | 실험 자극 조건 (두께·거리 백분위) |
| `results/pairs.csv` | 이창민, 한정훈 | 영역 쌍 원본 수치 |
| `results/regions.csv` | 이창민 | 영역별 색·기하 속성 |

**한정훈에게 전달할 때:** 두께는 5%와 50%, 거리는 25%와 75% 두 조건씩 잡으면
0.62 대비 환산 비율을 계산할 수 있다고 안내한다.

**완료 기준:** `conditions.md`에 실제 노선도 기준 수치가 채워지고 정훈에게 전달됨.

### 5. 파라미터 민감도 분석

**목표:** `n_segments`, `d_max`, `merge_thresh` 값의 근거를 수치로 확보한다.

| 파라미터 | 탐색 범위 | 측정 대상 |
|---|---|---|
| `n_segments` | 100, 200, 300, 500, 800, 1200 | 선 두께·글자 크기별 요소 검출률 |
| `d_max` | 50, 100, 200, 400, ∞ | 탐지 쌍 수와 공간 관계 분포 |
| `merge_thresh` | 4, 8, 12, 20, 30 | 영역 수와 중복 탐지 변화 |

예비 측정 결과 (합성 이미지, 선 두께 2px):

```
n_segments=300  → 혼동쌍 0개   (선이 배경에 흡수)
n_segments=800  → 혼동쌍 9개   (정상)
n_segments=2000 → 혼동쌍 144개 (과분할 중복)
```

**완료 기준:** `results/*_sweep.csv` 3개와 요약 표.

### 6. 실패 사례 분석

**목표:** 분할이 실패하는 조건을 유형별로 정리한다.

| 유형 | 판정 기준 |
|---|---|
| `merged_with_background` | 대상을 덮는 영역이 대상 면적의 4배 초과 |
| `fragmented` | 대상 위치에 겹치는 영역이 8개 초과 |
| `color_shifted` | 영역은 있으나 대표색이 대상과 크게 다름 |
| `not_covered` | 대상 위치를 덮는 영역이 없음 |

원본·분할 결과 이미지를 나란히 저장하고 CSV로 기록한다.

**완료 기준:** 유형별 대표 사례와 발생 건수 표.
