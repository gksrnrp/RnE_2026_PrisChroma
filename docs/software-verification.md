# 소프트웨어·연구 준비도 최종 검증 기록

최종 갱신일: 2026-09-17

## 1. 검증 범위와 결론

이 기록은 `src/`, `schemas/`, 계약 예제와 합성 산출물을 대상으로 한다. 아래의
2026-09-15 및 장치 정책 검증은 당시 구현의 역사적 기록이고, 현재 판단은
2026-09-17의 96/192/96회 설계 재검증을 우선한다. 최종 commit은 변경을 모두
검사한 뒤 기록한다.

결론은 다음 두 문장을 반드시 함께 읽어야 한다.

1. 구현·계약·무결성 차단의 핵심 회귀검사는 통과했지만, 새 설계의 기본 합성
   recovery는 대표 D384 bootstrap coverage 한 항목 때문에 `passed=false`다.
2. 실제 사람 응답은 0회이므로 굵기 효과, C192 우위, 실제 가독성 향상과
   적록색각이상자 일반에 대한 연구 결론은 아직 낼 수 없다.

## 4. 합성 parameter recovery

`results/parameter_recovery.synthetic.json`을 96/192/96회 배정과 현재 구현
해시로 다시 만들었다.

- simulation 200회, 대표 bootstrap 200회, seed 20260914
- 모든 적합 수렴, 세 low/central/high 난이도 profile의 오차 게이트는 모두 통과
- 모든 모형의 aggregate 수렴률 1.0
- D384 beta 부호 회복률 1.0
- 대표 B192·B384·C192의 진실값은 95% 구간에 포함됐으나 D384 beta 진실값
  `-0.48`은 단일 대표 자료의 구간 `[-0.444, 0.112]` 밖이어서 전체는
  **`passed=false`**다. 이 실패를 숨기거나 seed를 골라 바꾸지 않는다.
- 같은 기준 굵기 자료를 쓰는 B192/C192의 점추정·bootstrap 난수·표본 동일성 통과
- 산출물의 구현 파일 SHA-256을 현재 파일과 재대조해 통과
- `data_origin=synthetic`, `research_conclusion_allowed=false`

Aggregate C80 절대상대오차는 다음과 같다.

| 모형 | 중앙값 | 90백분위 |
|---|---:|---:|
| B192 | 0.0958 | 0.2576 |
| C192 | 0.1026 | 0.2290 |
| B384 | 0.0574 | 0.1701 |
| D384 | 0.0749 | 0.1870 |

이 값은 선택한 가상 진실값과 수준에서 분석기가 어느 정도로 모수를 되찾는지에
대한 개발 증거다. C192이 실제 사람에게 B192보다 낫다는 증거나 실제 연구의
효과크기가 아니다. 또한 현재 `passed=false` 결과는 사람 수집 승인이 아니다.
사람 수집 전에는 참가자별 동결 config의 실제 굵기·Lab
경로·lapse·12수준에 결합한 200회 recovery를 다시 통과해야 한다. validation
수집 전에는 실제 plan의 양자화 8수준에 결합한 별도 recovery도 필요하다.

## 5. 사람 연구 준비도

`research_readiness.py --format markdown`의 로컬 commit 후 결과는 통과 6,
차단 8이었다.
차단은 프로그램 실패가 아니라 없는 실제 자료를 결과로 꾸미지 못하게 하는
정상 상태다.

현재 통과:

- 합성 계약 표지
- 엄격한 사람 1.0 계약 스키마
- C80 심리측정 구현과 검사
- 재현 가능한 구현 commit
- 변경 없는 깨끗한 작업 폴더
- 핵심 문서의 연구 정체성 일치

현재 필수 차단:

- 참가자별 실제값으로 승인한 `experiment_config` 없음
- 실제 config-bound parameter recovery 없음
- calibration 384회 자료·매니페스트·적합 산출물 없음
- 동결 validation plan 및 plan-bound recovery 없음
- validation 64회×3블록 자료와 사람 검토 확정 없음
- 최종 `participant_thresholds` 없음

출처가 불완전한 지도 입력과 과거 지도표도 선택적 응용 근거로 사용할 수 없게
차단되어 있다. 이 항목은 주 4AFC 사람 실험의 필수 입력은 아니다.

## 6. 찾아서 고친 주요 연구 위험

1. 큰 패치의 0.62나 개발값 3.0이 선 C80 기본값으로 들어가던 가능성을 제거했다.
2. C80을 실제 4AFC 정답률 0.80으로 직접 파라미터화하고 chance 0.25와 고정
   lapse를 분리했다.
3. B192/C192은 같은 192회를 써서 자료량을 맞추고, B384/D384은 384회 비교로
   분리했다.
4. 검증 굵기는 점추정 차이가 아니라 paired bootstrap 95% 구간의 보수적 간격을
   먼저 최대화한다. 간격이 0이면 사전 구분 가능성 미확인으로 표시한다.
5. 검증 plan을 손으로 고치거나 중복 JSON key·재해시로 우회하지 못하게 모든
   후보 점수, 선택, 8수준과 해시를 재계산한다.
6. calibration 세 굵기의 공통 심리측정 기울기 가정을 자유 기울기 모형과 AIC로
   비교한다. 미수렴 또는 자유 모형 우세면 D384 beta 해석을 차단한다.
7. 같은 참가자의 validation 3블록을 독립 참가자/IID 표본으로 부르지 않는다.
   조건부 Bernoulli bootstrap은 학습·피로·연속상관에서 CI를 과소추정할 수 있음을
   명시했다.
8. 중단한 본 시행은 terminal로 처리하고 canonical JSONL을 바꿔 재시작하는
   우회를 차단했다. 합성/사람, practice/calibration/validation journal을 분리했다.
9. 사람 결과의 `confirmed=true`는 별도 검토 기록과 config·raw·plan·manifest
   SHA-256 및 검토 시각이 모두 일치할 때만 허용한다.
10. 연구용 보정은 측정한 Lab 중점·방향의 8-bit 유한 동일경로 후보를 전수
    비교한다. `ΔE00 >= C80`인 후보 전체에서 OKLab 이동 합 최소를 고르며 자극
    생성 허용오차로 후보를 잘못 제거하지 않는다.
11. 임의 RGB A/B/both 탐색은 근사 software baseline, 연구용 동일경로 탐색은
    선언한 유한 집합 안 정확 최소로 구분했다.
12. SLIC 합병, 1px 선폭, bbox 간격과 영역 충돌을 재감사해 수치 오류와 임의
    첫 색 채택을 수정했다.
13. 출처·license·원본 hash가 없는 지도 이미지와 낡은 성능표를 격리하고, 실제
    참가자일 가능성이 있는 예제 값을 합성 placeholder로 교체했다.

## 7. 남은 물리적·연구적 한계

- Machado 출력은 계산 좌표이며 특정 사람이 실제로 보는 색과 동일하다고 할 수
  없다.
- ΔE00는 화면 계측이 없으면 장치 독립적 절대 지각거리가 아니다.
- 참가자 2명 사례연구에서 protan/deutan 유형 차이와 개인차를 분리할 수 없다.
- C192의 결론은 동결한 장치·과제·Lab 경로와 측정 굵기 범위 안에 한정된다.
- 같은 참가자의 반복 block은 참가자 수준 독립 표본이 아니다.
- 보정 전후를 별도 사람 시행으로 비교하지 않으면 실제 가독성 향상을 주장할 수
  없다.
- 소프트웨어는 운영체제 밖에서 원장을 삭제·rollback하거나 자극 표시 직후 전원이
  끊긴 사실을 완전히 탐지할 수 없으므로 비공개 운영 기록과 보수적 제외가 필요하다.
- 원격 legacy 브랜치에 실제 참가자 자료일 가능성이 있는 파일이 있어 저장소
  관리자가 동의·공개 범위를 확인해야 한다. 해당 자료는 main에 병합하지 않았다.

## 8. 사람이 실제로 수행해야 연구가 끝나는 순서

정확한 실행 명령과 파일 인계는 `docs/changmin-runbook.md`를 따른다. 요약하면:

1. 지도교사·학교의 동의·철회·보관 절차를 확정한다.
2. 참가자별 가명 ID, type/severity와 독립 lapse 근거를 확정한다.
3. 실제 모니터 발광폭·해상도·배율·휘도·색관리·조명·관찰거리를 측정한다.
4. 1.0 config를 참가자별로 동결하고 config-bound recovery를 통과한다.
5. calibration PNG·sidecar·manifest를 만들고 실제 raster를 확인한다.
6. 참가자당 calibration은 현장 시간 측정 후 동결한 96회×4세션 또는 64회×6세션으로 총 384회를 수집한다.
7. B192/B384/C192/D384과 bootstrap을 적합하고 validation 굵기·8수준 plan을
   응답 전에 동결한다.
8. plan-bound recovery를 통과하고 validation 64회×3세션, 총 192회를 수집한다.
9. 블록 안정성, 범위 bracketing, 공통/자유 w, Δloss 95% 구간을 판정한다.
10. 같은 자극군의 모형별 C80을 유한 동일경로 최소 보정에 연결한다.
11. 실제 가독성 향상을 주장하려면 보정 전/후 미사용 색쌍의 별도 사람 검증을
    추가한다.

계획된 핵심 시행 수는 참가자당 576회, 두 명 총 1152회이며 연습은 별도다. 이
응답 자료가 없으므로 현재 완료된 것은 **연구를 정직하게 수행하고 판정할 수 있는
소프트웨어·사전 규칙·감사 체계**까지다.
