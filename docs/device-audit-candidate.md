# 실험 장치 자동조회 결과와 현장 확인표

조회일: 2026-09-14
상태: **후보값 — 사람 실험 설정으로 아직 동결하지 않음**

## 1. Windows에서 자동으로 읽힌 값

| 항목 | 조회값 | 최종 사용 조건 |
|---|---:|---|
| 활성 해상도 | 2880 × 1800 px | 실험 직전 Windows 설정과 GUI 런타임 검사를 모두 통과해야 함 |
| 주사율 | 120 Hz | 실험 전후 동일한지 확인 |
| EDID 제조사/제품 | SDC / 4189 | 실제 사용 화면과 같은지 확인 |
| EDID 표시영역 | 약 300 × 190 mm | EDID는 반올림될 수 있으므로 자로 직접 재측정 |
| Windows `AppliedDPI` | 192 DPI | 200% 배율 후보이며 설정 화면에서 직접 확인 |
| 운영체제 런타임 식별자 | Windows-11-10.0.26200-SP0 | 사람 세션 직전 GUI 자동 대조 |
| Python/Tk | CPython 3.13.15 / Tk 8.6.15 | 사람 세션 직전 GUI 자동 대조 |

기존 번들 런타임의 Tcl/Tk 불일치를 발견해 사람 GUI용 공식 Python
3.13.15/Tk 8.6.15를 설치하고 초기화까지 확인했다. 계산·렌더링·GUI는 최종
동결 전 이 한 환경에서 전체 검사를 다시 통과해야 한다.

자동조회는 실제 밝기, ICC 적용 결과, 야간모드, 주변 조도, 관찰거리, 화면의
실제 발광 색을 보증하지 않는다. 이 문서의 값을 그대로 복사해
`human_data_collection_allowed=true`로 바꾸면 안 된다.

## 2. 500 mm 관찰거리 가정의 굵기 계산

EDID 가로 300 mm와 2880 px를 가정한 픽셀 피치는 약 0.10417 mm/px이다.

| 교정 굵기 후보 | 시각도 | Szafir 선 측정범위 0.05–0.35° |
|---:|---:|---|
| 4 px | 0.04775° | 범위 밖 |
| 8 px | 0.09549° | 범위 안 |
| 16 px | 0.19099° | 범위 안 |
| 5 px | 0.05968° | 범위 안 |
| 10 px | 0.11937° | 범위 안 |
| 20 px | 0.23873° | 범위 안 |

따라서 **화면 가로 300 mm·관찰거리 500 mm가 직접 확인된다면** 교정 굵기
5/10/20 px와 held-out 후보 7/14 px가 현재 설계에 더 적합한 출발안이다.
이는 최종 선정이 아니다. 실제 관찰거리 또는 화면 폭이 달라지면
`src/plan_line_widths.py`로 다시 계산해야 한다.

## 3. 사람이 직접 확인하고 기록할 값

- [ ] 실험에 실제 사용할 화면의 가로 발광영역을 mm로 측정했다.
- [ ] Windows 해상도가 2880×1800이고 주사율이 세션마다 동일하다.
- [ ] Windows 배율과 앱 배율을 확인했고 GUI의 1:1 픽셀 검사를 통과했다.
- [ ] HDR, 야간모드, 자동 밝기, 색온도 자동변경을 껐다.
- [ ] 밝기와 ICC/색 프로파일 정책을 고정해 기록했다.
- [ ] 화면 휘도(cd/m²)를 실제 계측기로 재고 계측기·측정법을 기록했다. 추정값은 쓰지 않는다.
- [ ] 관찰거리와 이를 유지할 물리적 방법을 정했다.
- [ ] 주변 조명 위치와 조도 또는 재현 가능한 조명 조건을 기록했다.
- [ ] 화면 중앙 2×2 위치, 선 길이, 방향, 간격을 실제 PNG 캡처로 확인했다.
- [ ] 6–10회 연습에서 키 입력, 휴식, 중단, 재개, JSONL 저장을 확인했다.
- [ ] 세션 최대시간, 정기 휴식 간격·시간, 눈 피로·두통·철회 시 중단 규칙을 동결했다.

모든 확인이 끝난 뒤에만 실제 참가자별 비공개 1.0 설정 파일을 만들고,
설정 원문 SHA-256·코드 Git commit·자극 manifest를 함께 동결한다.
