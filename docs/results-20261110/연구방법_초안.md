# 연구 방법 (초안, 2026-11-09)

> 보고서 "연구 방법" 장에 옮기기 위한 초안이다. 수치는 실제 동결 설정 파일에서 가져왔다.
> 결과·해석 문장은 넣지 않았다.

## 1. 연구 개요

적록색각이상 참가자 2명을 대상으로, 고정된 표시 조건에서 선 굵기에 따라 두 색을 구별하는
능력이 어떻게 달라지는지 측정하는 사례연구다. 실험은 두 갈래로 진행했다.

- **본실험(교정 실험):** 참가자별 색각 모델에 맞춘 색쌍으로 4·8·16 px 선의 80% 정답 색차(C80)를 추정한다.
- **예비 탐색 실험:** 모든 참가자에게 같은 색을 쓰고, 1~3 px의 더 얇은 선까지 포함해 굵기 효과의 모양을 탐색한다.

## 2. 참가자

| 참가자 | 색각 유형 추정 | severity | 고정 실수율(lapse) | 추정 근거 |
|---|---|---:|---:|---|
| P01 | 적색약(protan) | 0.94 | 0.07 | 큰 패치 색 구별 검사 206회 |
| P02 | 녹색약(deutan) | 0.84 | 0.00 | 큰 패치 색 구별 검사 206회 |

- 색각 유형과 severity는 별도의 큰 색 패치 4지선다 검사 응답을 Machado(2009) 색각 시뮬레이션 모델에
  최대가능도로 맞춰 추정했다. 후보는 적색약·녹색약·정상 색각 세 가지다.
- severity는 임상 중증도가 아니라 "이 값을 넣었을 때 응답이 가장 잘 재현되는" 모델 값이며, 의학적 진단이 아니다.
- 모든 참가자는 가명 코드만 사용했고, 참여 전에 동의를 받았다. 언제든 불이익 없이 중단할 수 있음을 알렸다.

## 3. 실험 장치와 표시 조건

| 항목 | 값 |
|---|---|
| 모니터 | AOC U32N3G6R3B (발광 영역 가로 약 700 mm), 노트북에 연결 |
| 해상도·배율 | 3840×2160 px, Windows 배율 150%, 앱 배율 100% |
| 관찰거리 | 75 cm |
| 색 설정 | 모니터 sRGB 모드, 밝기 70%, 색도계 교정 없음(명목 sRGB) |
| 배경 | 회색 RGB(117, 117, 117) |
| 프로그램 | Python 3.13.15 / Tk 8.6.15, 미리 만든 PNG를 1:1 픽셀로 표시 |

- 화면에 PNG가 픽셀 그대로 표시되는지 전체화면 캡처로 확인했다. 4·8·16 px 선 모두 8,294,400픽셀 중 불일치 0이었다.
- 휘도계·색도계가 없어 실제 발광 색은 측정하지 않았다. 따라서 색차는 이 장치에서의 명목 sRGB 기준이다.

## 4. 본실험: 선 굵기별 C80 측정

### 4.1 과제

- **4지선다 다른 색 고르기(4AFC odd-one-out):** 화면 중앙 2×2 위치에 가로선 4개가 나오고, 그중 1개만 색이 다르다.
  참가자는 키보드 1~4로 다른 선을 고른다.
- 선은 길이 240 px, 안티앨리어싱 없는 직사각형이며 선 중심 간격은 320 px이다.
- 매 시행은 응시점 500 ms → 자극 → 응답(시간 제한 없음) → 시행 간 간격 500 ms 순서로 진행했다.
- 본 시행에는 정답 피드백을 주지 않았고, 연습 8회에만 피드백을 주었다.

### 4.2 선 굵기

| 굵기 | 시각도 | 시행 수 |
|---:|---:|---:|
| 4 px | 0.056° | 96 |
| 8 px (기준) | 0.111° | 192 |
| 16 px | 0.223° | 96 |

총 384회다. 세 굵기 모두 Szafir 선행 연구의 측정 범위(0.05~0.35°) 안에 들도록 정했다.

### 4.3 색 자극

- 두 색은 CIELAB 회색 중점 (L\*=65, a\*=0, b\*=0)에서 a\*(빨강-초록) 축을 따라 대칭으로 떨어진 색쌍이다.
- 색 차이는 참가자의 Machado 시뮬레이션을 거친 뒤의 CIEDE2000 색차(ΔE00)로 정의했다.
  각 수준마다 가장 가까운 8-bit 색쌍을 고르고, 실제 표시 RGB로 다시 계산한 값을 수준으로 고정했다.
- 색차 수준은 로그 간격 12단계다.
  - P01: 0.38 ~ 11.99
  - P02: 0.35 ~ 9.99. P02 모델에서는 이 색 경로로 만들 수 있는 최대 색차가 약 10.6이어서 상한을 10으로 낮췄다. 응답을 보기 전에 정했다.

### 4.4 진행 순서

- 64회씩 6개 블록으로 나눴다. 각 블록 안에서 굵기·색차·정답 위치·다른 색의 정체를 균형 있게 배정하고 순서를 섞었다.
- 32회마다 2분 휴식, 세션 최대 30분이다.
- 참가자가 원하거나 눈 피로·두통 등 불편함이 있으면 즉시 중단할 수 있게 했다.
  다만 자극 제시 중 중단된 블록이 있으면 그 참가자 자료는 확증 분석에서 제외하기로 미리 정했다.

### 4.5 분석

- 정답 확률 모형:
  `P(정답) = 0.25 + (0.75 − λ) · logistic(q80 + (ln x − ln C80) / w)`
  여기서 x는 시뮬레이션 후 색차, λ는 참가자별 고정 실수율이다. x = C80일 때 정답률이 정확히 80%가 되도록 q80을 정했다.
- 네 모형을 비교한다.

| 모형 | 사용 자료 | 내용 |
|---|---|---|
| B192 | 8 px 192회 | 굵기와 무관한 C80 하나 |
| B384 | 전체 384회 | 굵기와 무관한 C80 하나 |
| C192 | 8 px 192회 | 8 px C80에 Szafir 선행 모델의 굵기 비율을 적용 |
| D384 | 전체 384회 | C80 = C80_ref × (굵기/8 px)^β, β는 부호 제한 없이 추정 |

- 95% 신뢰구간은 모수적 bootstrap 1,000회로 구했다(D384는 BCa 구간).
- 굵기 효과는 D384의 β로 판단한다. β의 95% 신뢰구간이 0을 포함하면 "현재 정밀도로 굵기 효과 미확인"으로 보고한다.

### 4.6 사전 점검(parameter recovery)

- 실험 전에 정답을 아는 가상 참가자의 응답을 만들어, 같은 분석으로 C80과 β를 되찾는지 확인했다.
  가상 참가자 200명, bootstrap 200회, 반복 신뢰구간 점검 60회다.
- 두 참가자 모두 C80·β 점추정 오차와 수렴 기준은 통과했다.
  그러나 일부 모형에서 신뢰구간이 참값을 포함하는 비율이 기준(90%)에 못 미쳤다. P02는 87%였다.
- 그래서 교정 자료 수집만 진행하고, 신뢰구간에 근거한 확정 결론은 내리지 않기로 했다.

## 5. 예비 탐색 실험 (공통색, 얇은 선)

본실험과 별도의 탐색 실험이다. 모든 참가자에게 같은 색을 쓰고, 색차는 Machado 변환 없이
원본 sRGB의 CIEDE2000으로 계산한다. 따라서 본실험 C80과 숫자를 직접 비교하지 않는다.
표시 조건(배경, 선 길이, 2×2 4AFC)은 본실험과 같다.

| 단계 | 설계 | 문항 수 |
|---|---|---:|
| v2 | 공통색 경로 12개 × 2·4·8·16 px × 색차 6단계(큰 차이부터 제시) | 288 |
| v3 | v2에서 고른 색 경로 2개 × 1·2·3·4·8 px × 색차 3단계 × 8반복. 모든 굵기에 같은 RGB 색쌍 사용 | 240 |
| v4 | v3에서 측정하지 않은 6 px의 예측을 응답 전에 고정한 뒤 새로 측정 | 120 |

- v3 색 경로는 v2에서 굵기를 합산한 색차별 정답률로만 골랐고, 굵기별 성적은 선택에 쓰지 않았다.
- v3 분석은 세 모형을 비교한다. 굵기 무관, 로그 굵기에 따라 계속 변화, 4 px 이상에서 포화.
  한 굵기씩 빼고 예측하는 교차검증 점수(Brier, log loss)도 함께 본다.
- "4 px 이상에서 포화"는 v2·v3 결과를 본 뒤 세운 가설이다. 이 자료로 확인했다고 하지 않고, 탐색 결과로만 보고한다.

## 6. 후속 실험 설계

- v3 설계를 가상 참가자 시뮬레이션으로 점검했다. 4 px보다 굵은 선이 8 px 하나뿐이라,
  "4 px 이후 일정"과 "계속 변화"를 구별하는 힘이 약했다. 정답이 "4 px 꺾임"인 가상 참가자도
  53%만 그렇게 판정됐다.
- 후속 실험은 본실험이 아니라 예비실험 v3의 방식을 따른다. 공통 색 경로 2개, 색차 3단계, 모든 굵기에 같은 RGB 색쌍,
  선 길이 240 px, 배경 RGB 117, 2×2 4AFC, 관찰거리 75 cm 등 **굵기 외의 조건은 v3와 같게 유지한다.**
- 굵기만 **1·2·3·4·6·8·12·16 px** 8개로 늘려, 4 px 이상 구간에 굵기 4개를 둔다.
- 각 색 경로 × 굵기 × 색차 조합을 8회씩 반복한다. 그러면 정답 위치 4곳 × 다른 색 정체 2가지가 한 번씩 균형 있게 들어간다.
  총 2 × 8 × 3 × 8 = **384문항**이다.
- 이 설계는 시뮬레이션으로 정했다. 같은 240문항 안에서 굵기만 늘리면 "4 px 꺾임" 판별률이 오르지 않았고(57% → 56%),
  384문항에서는 68%로 올랐다. "계속 변화" 판별률은 71%에서 88%로 올랐다. 이 수치는 실제 응답이 아니라
  일반적인 가정값(색차 0.7·1.4·2.8, 기울기 2, 실수율 4%)과 가상 참가자 150명으로 계산한 설계 점검 결과다.
- **정상 색각 비교군:** 정상 색각자 1~2명이 같은 모니터·거리·설계로 후속 실험을 수행한다.
  얇은 선에서 구별이 어려워지는 경향이 적록색각이상 참가자에게만 나타나는지, 정상 색각에서도
  나타나는지 비교하기 위해서다. 비교군도 참가자별로 따로 분석하며, 집단 간 통계 검정은 하지 않는다.
- 분석은 참가자별로 따로 하고, 같은 경향이 여러 참가자에서 반복되는지를 본다(소수 참가자 집중 측정 설계).
  참가자 평균에 대한 집단 통계 검정이나 적록색각이상자 전체로의 일반화는 하지 않는다.

## 7. 원래 절차와 달라진 점 (보고서에 반드시 기재)
