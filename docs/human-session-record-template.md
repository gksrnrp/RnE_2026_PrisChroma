# 사람 실험 세션 운영 기록지(비공개 템플릿)

이 기록지는 프로그램이 알 수 없는 장치·동의·피로·예기치 않은 종료를 남기기
위한 운영 원장이다. **동의서 자체가 아니며**, 지도교사·학교가 승인한 절차와
함께 사용한다. 작성본에는 이름·학번·연락처를 쓰지 않고 공개 Git에 올리지 않는다.

## 2. 시작 전 확인

- [ ] 오늘 참여 의사와 중단·철회 권리를 다시 확인했다.
- [ ] 미성년자 본인·보호자 동의와 지도교사·학교 절차가 유효하다.
- [ ] 화면 모델·해상도·배율·물리 폭·관찰거리가 동결 config와 같다.
- [ ] HDR·야간모드·자동 밝기·자동 색온도 변경이 꺼져 있다.
- [ ] 휘도·색 프로파일·주변 조명 조건이 동결 기록과 같다.
- [ ] native Tk/Pillow 1:1 픽셀 표시와 전체화면 검사를 통과했다.
- [ ] config-bound 또는 plan-bound recovery와 준비도 게이트를 통과했다.
- [ ] 해당 phase의 canonical journal이 하나뿐이고 이전 중단 기록이 없다.

## 3. 세션 중 사건 기록

| UTC | 시행 ID | 사건·증상·편차 | 활성 자극이 보였는가 | 조치 |
|---|---:|---|---|---|
| | | | 예 / 아니오 / 불명 | |

다음 중 하나라도 발생하면 원자료를 삭제하거나 새 journal로 다시 시작하지 않는다.

- 본 시행 활성 자극 중 Esc 또는 참가자 중단
- 앱 강제 종료·전원 장애·운영체제 오류로 당시 자극 노출 여부를 확정할 수 없음
- 사전 고정한 최대 세션 시간 안에 block을 끝내지 못함
- 화면·거리·조명·색관리·코드·config·manifest가 도중에 바뀜

활성 자극 노출이 `예` 또는 `불명`인 예기치 않은 종료는 보수적으로 본 시행
중단으로 처리해 그 참가자 자료를 확증 분석에서 제외한다. 프로그램 저널에 행이
남지 않았더라도 이 운영 기록을 숨기거나 다른 파일로 우회하지 않는다.
